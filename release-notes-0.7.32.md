# BMS Data Platform 0.7.32 / BMS Gateway 0.4.7

## English

- Fixed false “Connection restored” records created during a normal desktop start.
- Event timestamps now include the date; stored standard events follow the selected interface language.
- Completed Russian and Ukrainian labels for the charge permission, password reminder and history synchronisation state.
- The synchronisation banner no longer claims legacy mode while it is only checking the phone cache.
- The Windows application now prevents duplicate instances and reports a clear error if port 4174 is occupied.
- The connection page lists available physical IPv4 addresses and prioritises non-virtual adapters.
- Android Gateway 0.4.7 includes the fast incremental history API and complete English, Ukrainian and Russian resources.
- Incomplete Android language packs are temporarily hidden to prevent mixed-language screens.

## Русский

- Убраны ложные записи «Связь восстановлена» при обычном запуске программы.
- В журнале теперь показываются дата и время, а стандартные события переводятся вместе с интерфейсом.
- Переведены разрешение заряда, напоминание о пароле и состояние синхронизации.
- Во время проверки истории больше не появляется ошибочная надпись о старом режиме загрузки.
- Запрещён повторный запуск второй копии Windows-программы; занятый порт 4174 теперь объясняется понятным сообщением.
- На странице подключения показываются доступные IPv4-адреса, физические сетевые адаптеры имеют приоритет.
- Android Gateway 0.4.7 содержит быструю дозагрузку истории и полные английский, украинский и русский переводы.
- Незавершённые языковые пакеты Android временно скрыты, чтобы интерфейс не смешивался с английским.
