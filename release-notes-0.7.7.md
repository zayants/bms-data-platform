# BMS Data Platform 0.7.7

- Added a simple/advanced diagnostics switch so basic users see only the essential monitor information.
- Added an in-app diagnostic methodology with practical read-only steps.
- Added optional Android GATT status codes to confirmed BMS connection-loss entries.
- GATT codes are hidden by default and can be enabled from Functions → Advanced diagnostics.
- Bundled Android gateway: BMS Gateway 0.3.8.
